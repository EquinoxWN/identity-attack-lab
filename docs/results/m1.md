## Analyze

The three paths are the ones the spec was written to contain: an ACL abuse ending in DCSync
(T1003.006), a Kerberoastable service account in a group that administers a workstation where a
domain admin is logged on (T1558.003), and an AS-REP roastable helpdesk user who can reset an IT
admin's password (T1558.004), which reaches the same session. The one defect found while writing
the tests: an `Aces` value that was an empty object (`{}`) was silently read as "no ACEs"; it is now
rejected (`_list_of`, covered by a malformed-file case).

## Improve and Control

The improvement is the drift check and the `verify` gate: changing any misconfiguration without
updating `expected_paths` fails `make ci`. Control: CI job `python` (lint, mypy, tests,
`render --check`, `isolation`, `verify`, `pip-audit`) and job `lab-static` (Packer validate,
`ruby -c` and `vagrant validate --ignore-provider` on the Vagrantfile, PowerShell parse).
